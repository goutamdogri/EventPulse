# EventPulse docs

## Guarantees and contract

- [Delivery guarantees](delivery-guarantees.md): what EventPulse promises, each claim mapped to the tests that prove it (checked by `make guarantees`, CI job `guarantees`).
- [Crash matrix](generated/crash-matrix.md): generated by `make correctness`, one row per named crash point (data: [crash-matrix.json](generated/crash-matrix.json)).
- [Test reports](generated/test-reports/): stamped e2e and correctness results the guarantees are checked against.
- [Outbox measurements](generated/outbox-measurements.json): latency, failover and Kafka-outage numbers from the outbox tests.
- [API contract](api-contract.md): ingest API, idempotency, time fields, wire format, admin API and `config.changed`.

## Architecture decisions

| ADR | Decision |
| --- | --- |
| [0001](adr/0001-kafka-client-library.md) | Kafka client library for the Node services |
| [0002](adr/0002-offsets-in-db-vs-key-dedup.md) | Sink idempotency by key `(tenant_id, event_id)`; offsets stay in Kafka |
| [0003](adr/0003-dedup-placement.md) | Two dedup layers; correctness only in the sink |
| [0004](adr/0004-redis-vs-postgres-idempotency.md) | Redis for the API idempotency store |
| [0005](adr/0005-avro-vs-protobuf.md) | Avro with a Schema Registry for `events.raw` |
| [0006](adr/0006-retry-topics-vs-in-process.md) | Retry tiers on Kafka topics, DLQ with an index |
| [0007](adr/0007-polling-outbox-vs-cdc.md) | Transactional outbox with a polling, single-leader relay |
| [0008](adr/0008-event-time-and-order-insensitivity.md) | Event time rules, skew bounds at the API, order-insensitive sink |
